# Documentación del Proyecto Pergamino

## Estructura de la Documentación

La documentación del proyecto se ha organizado en las siguientes categorías:

### 1. Arquitectura
Documentación sobre la arquitectura general del sistema, incluyendo diagramas, flujos y componentes principales.

### 2. Guías
Manuales de usuario, guías de desarrollo y tutoriales para diversas funcionalidades.

### 3. Decisiones
Registros de decisiones arquitectónicas (ADRs) y documentación sobre las elecciones técnicas realizadas.

### 4. Seguridad
Información sobre la implementación de seguridad, configuraciones de Firebase y políticas de acceso.
